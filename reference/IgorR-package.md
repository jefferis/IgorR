# Read binary files saved by Igor Pro (including Neuromatic data)

This package provides function to read data from the Igor Pro data
analysis program by Wavemetrics. The data formats supported are Igor
packed experiment format (`.pxp`) and Igor binary wave (`.ibw`). See:
<https://www.wavemetrics.com/> for details.

## Details

It also includes some functions to load special pxp files produced by
the Neuromatic/Nclamp packages for recording and analysing neuronal
\#data. See <https://github.com/SilverLabUCL/NeuroMatic> for details.

Key functions in the package include
[`read.ibw`](https://jefferis.github.io/IgorR/reference/read.ibw.md),
[`read.pxp`](https://jefferis.github.io/IgorR/reference/read.pxp.md).
