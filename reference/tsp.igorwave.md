# Return tsp attribute of Igor wave (start, end, frequency)

Note that end = (npts-1) \* deltat

## Usage

``` r
tsp.igorwave(wave)
```

## Arguments

- wave:

  Igor wave loaded by `read.ibw` or`read.pxp`

## Value

numeric vector with elements start, end, frequency
